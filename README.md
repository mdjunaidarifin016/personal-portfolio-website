# Personal Portfolio Website

A simple and modern personal portfolio website built using HTML and CSS.

## Features

- Clean and modern UI
- Navigation bar with search box
- Animated typing text effect
- Gradient buttons with hover effects
- Profile illustration and background design
- Social media icons

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts

## Project Structure

```text
personal-portfolio-website/
│
├── index.html
├── style.css
└── images/
    ├── logo.png
    ├── background.png
    └── profile-image.png
```

## Getting Started

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL : https://github.com/mdjunaidarifin016/personal-portfolio-website.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
